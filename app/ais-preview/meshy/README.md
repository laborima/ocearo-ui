# Modèles AIS générés par Meshy

Déposez ici les `.glb` générés par Meshy, nommés par code AIS :

```
ais-20.glb   WIG (effet de sol)
ais-30.glb   Pêche
ais-31.glb   Remorqueur
ais-35.glb   Militaire
ais-36.glb   Voilier
ais-37.glb   Plaisance
ais-40.glb   Navire rapide (HSC)
ais-50.glb   Pilote / spécial
ais-60.glb   Passagers
ais-70.glb   Cargo
ais-80.glb   Pétrolier (tanker)
```

Le script `models/ais/generate.sh` peut écrire directement ici via la variable
`OUTDIR` (par défaut il pointe sur ce dossier).

La page `../index.html` les charge automatiquement ; un type sans fichier
affiche « à générer ».
